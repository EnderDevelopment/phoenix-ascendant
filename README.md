# Phoenix Ascendant

Phoenix Ascendant is a Roblox game where players control a Phoenix character that grows from a child to an adult. The game features various skills, combos, and special combos, including an ultimate humanoid Phoenix skill that involves a sword. Players can engage in combat, use special abilities, and experience the evolution of their Phoenix character.

## Install

1. Open Roblox Studio.
2. Create a new place.
3. Copy the scripts from the `src` folder in this repository.
4. Paste the scripts into the appropriate locations in Roblox Studio.

## Use

1. Run the game in Roblox Studio.
2. Spawn the character by connecting the scripts to the player.
3. Use the basic skills, combos, and special combos by triggering the respective scripts.
4. Unlock achievements and level up by gaining XP.
5. Enjoy the ultimate Phoenix skills, including the Phoenix Sword.
